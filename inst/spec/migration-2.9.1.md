# Migrating from neurogeo 2.9.0 to 2.9.1

No code migration is required. Version 2.9.1 is a documentation and
conformance-maintenance release.

Consumers may use the corrected installed `spec/supported-formats.md` as the
authoritative capability inventory. Existing objects, exchange bundles,
CIFTI files, BIDS derivatives, and function calls remain compatible.

# neurogeo API 4.2.1

Version 4.2.1 adds no public function, class, argument, return field,
estimator, or NGCS schema.

The release adds discovery metadata, an installed citation, executable
examples for the main workflows, a public API tier inventory, and
line-coverage governance. These are package usability and maintenance
changes. Version 4.2.1 implements the same NGCS 3.5 contracts and numerical
semantics as 4.2.0.

The API tiers are descriptive navigation aids. They do not weaken backward
compatibility for advanced or exchange/governance functions.

# neurogeo 2.5 API

`write_ngeo_cifti()`, `ngeo_delayed_values()`, `ngeo_value_chunks()`,
`ngeo_block_support_map()`, `ngeo_validate_block_support_map()`,
`ngeo_materialize_support_map()`, `ngeo_change_support_block()`,
`ngeo_bids_sidecar()`, and `write_ngeo_bids_derivative()` implement the
NGCS 2.5 scalable I/O contract. All neurogeo 2.4 APIs remain available.

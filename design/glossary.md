# Glossary

- **domain**: the ordered collection of spatial support elements represented
  by one dataset.
- **element**: one vertex, active voxel, point, grayordinate, or region.
- **support**: the spatial extent represented by an element or measurement.
- **space**: the declared coordinate or template context.
- **topology**: direct connection, such as a mesh edge or voxel neighbor.
- **metric**: a named rule for distance.
- **map**: one values-block column.
- **measurement semantics**: rules describing whether a map is intensive,
  extensive, a count, categorical, or unknown.
- **partition**: a domain-bound mapping from base elements to regions.
- **grayordinate**: one ordered surface or volume element in a composite
  CIFTI brain-model domain.
- **provenance**: auditable source and operation history.

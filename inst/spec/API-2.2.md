# neurogeo 2.2 API summary

- covariance: `ngeo_support_covariance()`,
  `ngeo_validate_support_covariance()`;
- propagation: `ngeo_support_uncertainty()`;
- ensembles: `ngeo_support_ensemble()`,
  `ngeo_registration_ensemble()`, `ngeo_segmentation_ensemble()`,
  `ngeo_validate_support_ensemble()`;
- conditioning: `ngeo_support_condition()`;
- enhanced diagnostics and sensitivity:
  `ngeo_support_diagnostics()`, `ngeo_support_sensitivity()`.

# Core concepts

**Language:** [简体中文](/concepts/)

Start with [objects and measurement semantics](/en/tutorials/core-concepts),
then choose the workflow that matches your data support. The
[runtime-options reference](/en/concepts/options) lists package-wide safety
ceilings; per-operation resource limits belong in `ngeo_resource_budget()`.

The glossary defines user-facing terms. Method pages state their spatial null,
exchangeability assumptions, and output interpretation alongside runnable code.

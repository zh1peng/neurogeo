# neurogeo 2.4 API

- `ngeo_fit_variogram()` fits bounded spherical, exponential, or Gaussian
  WLS models.
- `ngeo_kriging()` performs bounded local ordinary or universal kriging with
  prediction variance.
- `ngeo_gwr_bandwidth()` and `ngeo_gwr()` provide deterministic CV, local
  coefficients, effective sample size, and conditioning.
- `ngeo_spatial_regression()` unifies OLS, SLX, exact bounded SAR, and SEM.
- `ngeo_car()` provides foundational proper/intrinsic Gaussian CAR smoothing
  with explicit constraints.
- `ngeo_support_model()` fits and compares a declared model across complete
  support maps.

All neurogeo 2.3 APIs remain available.

# neurogeo API 4.2.2

Version 4.2.2 adds no public function, class, argument, return field, NGCS
schema, or numerical estimand. It adds a download-only, checksum-verified
real-data release-validation surface for NIfTI, GIFTI/FreeSurfer, CIFTI, and
atlas/change-of-support workflows.

The external fixture cache is not part of the installed package, runtime API,
or dependency graph. Existing format, measurement-semantics, support-map,
and provenance contracts are unchanged.

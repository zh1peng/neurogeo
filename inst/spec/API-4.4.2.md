# neurogeo 4.4.2 API contract

Version 4.4.2 adds no public function, class, or object schema.

The stable public API remains the 4.4.1 API. This maintenance version:

- makes `inst/spec/` the single canonical source for installed contracts;
- removes obsolete archive/Release construction code and tracked validation
  logs;
- keeps generated website copies of cortical figures out of version control;
- retains the full validation and performance gates under maintenance-focused
  names.

Scientific estimators, five domain types, alignment invariants, and the
one-domain/one-values-block object contract are unchanged.

# neurogeo 2.3 API

- `ngeo_common_support_test()` applies permutation, Moran spectral, or
  surface-spin common-source nulls across support-map families.
- `ngeo_support_adjust()` provides BH, BY, Holm, and common-simulation max-T.
- `ngeo_cross_atlas_consensus()` provides fixed/random effects,
  heterogeneity, intervals, and leave-one-atlas-out influence.
- `ngeo_multiscale_inference()` evaluates a declared ordered scale family.
- `ngeo_boundary_test()` tests effect dispersion over a validated
  segmentation ensemble.
- `ngeo_atlas_robust_effect()` adds confidence intervals, consensus,
  influence, and optional paired-source bootstrap.

All neurogeo 2.2 APIs remain available.
